# SmartHome — E-commerce Frontend

A smart home e-commerce frontend built with React and TypeScript.

> 🚧 **Status: Under active development.**
> This project is being built step by step and updated regularly.
> Some pages and features are not finished yet (see the Roadmap below).

## Features

- Home page with hero and featured products
- Products page with search, category filter and "Load More"
- Product details page (dynamic route)
- Cart and wishlist managed with Redux Toolkit
- Live cart counter in the navbar
- Responsive layout

## Tech Stack

- React 19, TypeScript, Vite
- Tailwind CSS v4
- Redux Toolkit
- React Router

## Getting Started

    npm install
    npm run dev

## Project Structure

    src/
    ├── app/          router and store
    ├── components/   shared UI (common, layout, product)
    ├── features/     cart, home, products, wishlist
    └── styles/
